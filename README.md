## 这玩意儿是什么

一个跑在浏览器里的「虚拟小手机」。打开就是一台手机，里面有通讯录、聊天、通话、朋友圈和各种小 App，角色由你自己捏，聊天走你自己的 AI 接口。

没有账号、没有服务器数据库，数据都在你自己的浏览器里。换句话说：手机是你的，隐私也是你的，弄丢了别找我哭（但可以找我修）。

## 能做什么

- **角色聊天**：多角色、独立人设、聊天风格、语音、语言/时区/和你的距离。
- **长期记忆**：短期 → 长期 → 核心三层记忆，可接独立的记忆接口；支持 Embedding 向量语义检索。
- **世界书**：全局或角色绑定，关键词触发、权重、概率、注入深度都能调。
- **捏捏**：给个大概思路，AI 帮你补全人设表格和世界书，写完直接导入通讯录。
- **通话 / 语音**：语音条可点播放，长按转文字；外语角色点气泡看中文。
- **小 App**：朋友圈、论坛、商城、外卖、邮箱、日记、日程、小说、音乐等。
- **双语角色**：非中文角色按「原文|简体中文译文」输出，界面默认只显示原文。
- **备份还原**：整机导出/导入，图片一起打包。

## 快速开始

### 浏览器

```bash
npm install
npm start
```

然后打开 <http://localhost:3000>。第一次进去先去「设置」把接口填上，不然角色只会已读不回。

### 部署到 Vercel

推到 GitHub 后导入 Vercel 即可，`api/` 下的接口会自动变成 Serverless 函数。前端也可以直接静态托管，接口填自己的直连地址。

### 安卓 APK

`android/` 是套壳工程，`public/` 会被打进 WebView。装好后如果没收到更新提示，先确认网络能连到部署地址，再点一次「检查更新」。

## 接口怎么配

设置页里能分别配置这些，互不打扰：

| 配置 | 用途 |
| --- | --- |
| 聊天接口 | 角色聊天、通话、大部分生成 |
| 记忆服务 | 整理短期/长期/核心记忆 |
| 向量记忆 | Embedding 语义索引，地址留空会借用记忆服务 |
| 语音服务 | 角色语音（TTS） |
| 生图服务 | 角色外观与聊天配图 |
| 工具 API | 翻译、论坛、购物、外卖、捏捏各自一套 |

工具 API 里哪一项留空，就自动借用聊天接口。翻译只在你点外语气泡时调用，不会偷偷跑额度。

接口需要兼容 OpenAI 的 `/chat/completions`，地址一般填到 `/v1` 这一层。

## 数据存在哪

- **localStorage**：接口配置、开关这类小东西。
- **IndexedDB**（库名 `clearcall`）：聊天记录、角色、记忆、各 App 存档；图片以 Blob 存在 `files`。
- **备份**：设置里的导出/导入会把图片转成 base64 一起带走。

换浏览器、清缓存、无痕模式关掉，数据就没了。重要角色记得导出备份，别等丢了再来找余叔叔，那时候我也只能陪你叹气。

## 几个容易踩的坑

- **504 / 服务商过载**：接口超时是 15 秒，超了就是服务商那边忙，换个模型或者稍后再试。
- **消息不拆条**：多条消息用 `<split>` 分隔，不是按句号自动切。
- **记忆不更新**：先看记忆服务有没有配、模型能不能正常返回；再看聊天是否真的产生了新消息。
- **向量记忆没生效**：确认 Embedding 模型填的是向量模型（不是聊天模型），旧记忆会在后台慢慢补索引。
- **语音条没声音**：语音服务没配好，或者浏览器拦了自动播放，点一下再试。
